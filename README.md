# EDEXORA-online-academy

**EDEXORA — From Learning to Excellence**  
Personalised 1-on-1 Online Tuition, Madrasa Education & Language Learning for students in Kerala and Gulf countries (KG to Class 10).

## Quick Start

```bash
# Build static pages
node src/build.js

# Run production server (http://localhost:3000)
node server.js

# Run automated test suite
node test.js
```

See [HANDOVER.md](./HANDOVER.md) for deployment, Google Sheets integration, and configuration details.
